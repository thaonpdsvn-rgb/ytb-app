HangUp Uploader

A personal tool that uses YouTube API Services to upload and schedule videos on the owner's own channel Hang Up Now Stories.

Privacy Policy · Terms of Service · YouTube Terms of Service · Google Privacy Policy

Privacy Policy – HangUp Uploader

Last updated: 2 November 2026

HangUp Uploader is a small personal tool used by one person, the owner of the YouTube channel Hang Up Now Stories, to upload and schedule that owner's own videos through the YouTube Data API. It is not a public service and is not offered to any other users.

What the tool accesses

With the channel owner's explicit authorization (Google OAuth), the tool can upload videos to the owner's own channel, set their title, description and thumbnail, add them to the owner's own playlists, and update the channel's own description and banner, read the channel's own video statistics, and post comments on the owner's own videos. It accesses no data about any other YouTube user or viewer.

What data is collected and stored

The tool does not collect personal data from any visitor or viewer. The only credential it stores is the owner's OAuth access/refresh token, kept locally on the owner's own computer in a file with restricted permissions. The token is never sent to any server other than Google's, and is never shared with or sold to third parties.

Use of Google user data

HangUp Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data from the YouTube API is used only to perform the uploads and settings described above, and is not used for advertising, analytics, or sold.

YouTube API Services

This tool uses YouTube API Services. By using YouTube features you are also bound by the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

The channel owner can revoke the tool's access at any time at myaccount.google.com/permissions and may delete the stored token file from their computer.

Contact

Questions can be sent through the channel's page: youtube.com/@HangUpNowStories.

Last updated: 2 November 2026

HangUp Uploader is a private, non-commercial tool for the owner of the "Hang Up Now Stories" channel. It is not offered to the public and has no other users. It is provided as is, without warranty, and is used only to publish the owner's own content.

By using YouTube features through this tool, the channel owner agrees to be bound by the YouTube Terms of Service and the YouTube API Services Terms of Service.
